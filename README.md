# ShopSphere – Premium Shopping

ShopSphere is a modern, responsive e-commerce web application designed to deliver a seamless and user-friendly online shopping experience. It provides customers with an intuitive platform to explore a diverse collection of products across multiple categories, including Fashion, Accessories, Electronics, and Lifestyle.

The website incorporates essential e-commerce functionalities such as product browsing, real-time search, category-based filtering, sorting, stock availability indicators, and an interactive shopping cart. Customers can add or remove products, manage cart quantities, and view dynamically calculated order totals.

ShopSphere also features a structured checkout process that collects customer delivery information and provides an order confirmation experience. Its interface is designed with a premium aesthetic, responsive layouts, and interactive elements to simulate the functionality of a modern online retail platform.

### Key Features
- **Product Catalogue:** Wide range of products across multiple shopping categories.
- **Smart Search:** Quickly find products using the search functionality.
- **Category Filtering:** Browse products based on specific categories.
- **Product Sorting:** Organise products according to available sorting options.
- **Stock Availability:** Display remaining product quantities.
- **Interactive Shopping Cart:** Add, remove, and manage products.
- **Checkout System:** Collect customer delivery addresses and order details.
- **Order Management:** Order confirmation and tracking workflow.
- **Responsive UI:** Optimised interface for different screen sizes.
- **Local Storage:** Maintain cart data across browser sessions.

### Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling, animations, and responsive design.
- JavaScript – Dynamic functionality and interactive features.
- Local Storage – Client-side data persistence.

**Project Objective:** To develop a functional and aesthetically appealing e-commerce platform that demonstrates practical implementation of front-end web development concepts, DOM manipulation, event handling, data management, and responsive user interface design.
